HelioFITS Peek

Quick Look plugin for FITS files

Solar FITS files, rendered as the Sun: in the right instrument colormap, with real coordinates, right where your data already lives.

Get it on the Mac App StoreVersion 1.5.2 · Free · macOS Direct downloadVersion 1.5.2 · Notarized zip · macOS Install with HomebrewVersion · macOS 14.5 or later

Install with Homebrew

Homebrew currently has HelioFITS Peek .

Install

brew tap GillySpace27/tap
brew install --cask gillyspace27/tap/hfpeek

Update

brew update
brew upgrade --cask gillyspace27/tap/hfpeek

If Homebrew refuses the tap as untrusted, run brew trust gillyspace27/tap once, then install again. Needs macOS 14.5 or later. This installs the direct download, not the App Store copy; use one or the other.
