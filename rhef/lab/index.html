RHEF Lab

Drop a solar FITS file and see it through RHEF. It runs in this page: the file never leaves your computer.

Not data: a made-up Sun, drawn by this page.

Version 1 reads uncompressed FITS images (BITPIX 8, 16, 32, 64, -32, -64). Tile-compressed files (RICE_1, as most PUNCH Level 3 files are) are not read yet.

Original RHEF

Point at the image for a pixel's rank in its ring.

The left of the wipe is the file at a linear scale (1st to 99.5th percentile); the right is RHEF: each value ranked within its ring around the Sun's centre, then the Upsilon curve (split at 0.5) if it is on. Rings are equal width out to the farthest pixel, half as many as the image has rows. Frames over 4096 pixels on a side are halved first, and the page says so. RHEF output is a visualization, not a calibrated radiance. Method: Gilly & Cranmer (2025), Solar Physics, doi:10.1007/s11207-025-02578-x.
