RHEF

The Radial Histogram Equalizing Filter. Solar images usually show a bright ball in a dark void; RHEF shows the corona that is actually there, on the disk and off the limb, with no parameters to tune.

pip install sunkit-image
import sunpy.map
from sunkit_image.radial import rhef

rhef(sunpy.map.Map("aia_171.fits")).peek()

The paper (Solar Physics, 2025) Worked example API reference Try it in your browser

  • Works frame by frame, so movies need no dataset-wide statistics.
  • Treats the disk and the off-limb corona the same way across the whole field of view.
  • Optional Upsilon tone curve, a symmetric cousin of gamma correction, for finer control.
  • Part of sunkit-image, SunPy's image-processing package. An IDL version is described in the paper.

How it works

RHEF splits the image into rings around the Sun's centre and replaces each value by its rank among the values in its ring. A faint ring and a bright ring then both span the whole range from dark to light.
