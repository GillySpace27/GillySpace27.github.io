Every release of the family, newest first. Also as an Atom feed.

  • HelioFITS Studio 0.8.8 · 2026-10-28 · GitHub pre-release
    Pizza, on the toolbar, cuts every shown image layer into its own wedges, squares or polar tiles of one Sun, so the same patch of the Sun is seen through every filter side by side. Nothing is resampled: each layer is drawn whole and keeps only its own cells. Wedges can be labelled with each channel's wavelength, the turn is animatable, and a spin can be recorded as a movie. Release page
  • HelioFITS Studio 0.8.7 · 2026-10-21 · GitHub pre-release
    New Layer is a button again, not a dropdown: it opens one window with a tab for each source. HV (JPEG 2000) streams Helioviewer's browse images, VSO (FITS) queries the Virtual Solar Observatory, Direct (FITS) opens a mission's own archive (PUNCH, SOAR, ASPIICS, MLSO) or loads LASCO from NRL, and Heliad (Local FITS Cache) lists what the Heliad app has already downloaded. The window has its own time range and time step (or frame count) at the top, which every tab uses. They start as the master ones beside New Layer each time it opens, and changing them affects only the layer being added, never the master range; PUNCH, SOAR and MLSO open on that range, PUNCH on that time step too. It opens on the tab used last. Layers > New Image Layer... (Cmd-N) opens the same window. Release page
  • HelioFITS Studio 0.8.6 · 2026-10-11 · GitHub pre-release
    Send Feedback and the Report this... button on error dialogs now reach Gilly. Until reports can be sent directly, the button reads Send by Email...: it opens an email to gilly@nwra.com in your mail program, with your note, the version, the system and the top of the error filled in, and shows the full saved report (and screenshot, if you took one) in Finder or your file manager so you can attach it Release page
  • HelioFITS Studio 0.8.5 · 2026-10-07 · GitHub pre-release
    A Welcome window opens on launch with the version, What's New for this version (read from the app itself, no network needed), and four ways to start: Continue, Start Blank, Open Session and Take the Tour. Help > Welcome to HelioFITS Studio reopens it, and a checkbox stops it opening at startup Release page
  • Heliograph 0.7 · 2026-09-28 · direct download
    Heliograph now updates itself. It checks once a day, downloads in the background and installs when you quit; a kiosk installs overnight. Release page
  • HelioFITS Studio 0.8.3 · 2026-09-24 · GitHub pre-release
    FITS files that hold more than one image now load. PUNCH's polarized mosaics (PAM, PTM) carry two or three images in one file, and earlier builds refused them. Each image is named from the file's own OBSLAYR keywords, such as PolarB and PolarpB Release page
