The contracts that two HelioSoftware tools depend on, written down once, with checksums so a copy that drifts is caught.

Using it from another repository

Keep a copy of this folder next to your checkout and point the check at it. The check reads the marker a copied file carries and says whether the copy still matches its source.

export HELIOSOFTWARE_SPEC_DIR=~/vscode/Website/heliosoftware/spec
python3 check_spec.py CLAUDE.md
python3 spec_sums.py --check

Two markers are understood. A copied block of text sits between <!-- heliosoftware-preamble v1 sha256=<hex> --> and <!-- /heliosoftware-preamble -->. A copied file starts, on line 1 or on line 2 after a shebang, with # heliosoftware-vendored: <label>:<path> sha256=<hex> (// or ; in other comment syntaxes). The hash is of the file with that one line removed. Exit codes: 0 all copies match, 1 a copy has drifted, 2 a file carries neither marker.

Rules

  • Additive only. A contract that other software reads gets a new version beside the old one; an old version stays where it is.
  • Every file in this folder is listed with its checksum in SHA256SUMS. python3 spec_sums.py --write is the only thing that writes that file.
  • RHEF output is a visualization, not a calibrated radiance.
