HFStudio

A desktop viewer for the Sun's outer corona, built for PUNCH, LASCO and other coronagraph data.

Download for Mac

Version 0.8.1 · Apple Silicon Macs · pre-release

Field guide (PDF) GitHub repository

  • Open the disk image and drag HFStudio to Applications. Java comes with it.
  • Intel Mac, Linux or Windows: get the zip, install Java 25, and start run.command, run.sh or run.bat. Linux and Windows are new, so please tell us how it goes.
