Installing, on every platform
  • Mac (Apple Silicon): open the disk image and drag the application to Applications. Java comes with it.
  • Intel Mac: the Intel disk image (0.8.3; 0.8.5 has none) installs the same way.
  • Windows: the Windows zip is a portable app; no administrator rights are needed. Right-click it, choose Extract All, then run HFStudio\HFStudio.exe in the folder it makes. It is not code-signed yet, so Windows may warn about an unknown publisher; choose More info, then Run anyway.
  • Linux: unpack the Linux archive anywhere and run HFStudio/bin/HFStudio. Java comes with it.
  • Early builds: the Intel Mac, Windows and Linux packages carry their own Java and pass our automated checks, but they are newer than the Mac one, so please tell us how they go.
  • Anything else: the cross-platform zip runs wherever Java 25 is installed: start run.command, run.sh or run.bat.
  • The downloads are named HFStudio, the application's short technical name.
  • Older versions stay available on the releases page.
