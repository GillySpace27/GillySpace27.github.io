Installing, and other platforms
  • Mac: open the disk image and drag the application to Applications. Java comes with it.
  • Intel Mac, Windows or Linux, if you want to try early: these packages carry their own Java and pass our automated checks, but nobody has run them on a real machine yet, so please tell us how it goes.
    • Intel Mac disk image: install as above.
    • Windows zip: unzip it anywhere and run the .exe inside the folder it makes. It is not code-signed yet, so Windows may warn about an unknown publisher; choose More info, then Run anyway.
    • Linux archive: unpack it anywhere and run the launcher in its bin folder.
  • Anything else: the cross-platform zip runs wherever Java 25 is installed: start run.command, run.sh or run.bat.
  • The downloads are named HFStudio, the application's short technical name.
  • Older versions stay available on the releases page.
